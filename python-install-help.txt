這台電腦還沒有安裝 Python，請先照下面做（只要做一次）：


【1】用瀏覽器打開這個網址

      https://www.python.org/downloads/


【2】按網頁上黃色那顆大按鈕

      Download Python 3.x.x

      （3.x.x 是版本號，是多少都可以）


【3】打開剛剛下載好的檔案（在「下載」資料夾裡）


【4】※※※ 這步最重要，很多人卡在這裡 ※※※

      安裝畫面的「最下面」有一個小方框，
      旁邊寫著：

            Add python.exe to PATH

      這個方框「一定要打勾」！

      沒打勾的話，後面每一步都會失敗。


【5】打勾之後，按 Install Now


【6】等它跑完，出現 Setup was successful 就按 Close


【7】回到 PTT 監控的資料夾，
      重新點兩下「1_安裝.bat」


如果第 4 步已經按下去才發現忘記打勾：
沒關係，重新打開那個下載的安裝檔，
選 Modify 或直接重裝一次，記得打勾就好。
